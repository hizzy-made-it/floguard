# Reading a Website Quiz Lead — Rep Guide

Leads from floguardfl.com's 12-step drainage quiz arrive with **discovery already done**. Read the quiz block in the lead's notes before dialing — then don't re-ask what they already told you.

## The quiz fields and what they tell you

| Field | Sales meaning |
|---|---|
| `issues` | Which playbook to open: crawlspace/foundation → SumpPump; lanai/patio → YardDrainage; standing water → FrenchDrain |
| `water_location` | "Around the foundation" or "Crawlspace" = structural risk = urgency. "Backyard" alone = comfort/usability pitch |
| `water_duration` | The severity dial: "Several days" / "Never fully dries" = chronic groundwater = French drain conversation |
| `frequency` | "Every time it rains" beats "only heavy storms" — repetition = compounding damage frame |
| `affected_size` | Scope hint — sets assessment expectations, never a phone quote |
| `existing_drainage` | "An old French drain" = likely unlined/clogged (see burned-owner objection). "A sump pump" = Maintenance/upgrade angle |
| `damages` | Gold: "Foundation cracks or moisture", "Mold or musty smell", "Water inside" — these are the ROI reframe, in their own words |
| `timeline` | "ASAP" = call within the hour. "Just researching" = nurture cadence, no pressure |
| `property_type` | "Rental property" / "Commercial" → PropertyMgmt playbook and B2B tone |
| `location` | Neighborhood social proof ammo |
| photos | Look before you call — reference what you see |

## The call

Open by proving you read it: "You mentioned water stands around the foundation for a few days after every storm — that's exactly the pattern we engineer against."
Then: one confirming question, the tailored pitch, and the assessment close. Quiz leads are warm — the close rate lives or dies on speed to first call (target: same day).

## Scoring

Quiz answers feed the Drainage Need Score (see DRAINAGE-NEED-SCORE.md). An urgent-band DNS from quiz data = first-priority dial.
