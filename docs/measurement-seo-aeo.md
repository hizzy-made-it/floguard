# FloGuard SEO + AEO Measurement Setup (Full Guidance)

## Required Tools (Start Here)
1. Google Search Console
   - Add property: https://www.floguardfl.com
   - Verify via DNS or HTML tag (use existing meta)
   - Submit sitemap: https://www.floguardfl.com/sitemap.xml
   - Set up email alerts for errors

2. Google Analytics 4
   - Link property to GSC
   - Enable enhanced measurement
   - Create custom events/conversions for:
     - Form submissions (lead form, quiz, contact)
     - Phone clicks
     - Assessment requests
   - Key reports: Acquisition > Organic Search; Engagement > Pages; Conversions

3. Google Business Profile
   - Full optimization as per GBP checklist
   - Track insights: searches, views, actions

4. Rank Tracking
   - Free: Manual in Google or SERP API
   - Recommended: SERPWatcher or similar (~$20/mo for 100 keywords)
   - Track list from keyword-research.md
   - Weekly checks, group by category (commercial, local, AEO)

## AEO Monitoring
- Weekly manual searches in:
  - Perplexity.ai
  - ChatGPT (search mode)
  - Gemini, Copilot
- Queries from keyword list AEO variants
- Log: Date, Query, Was FloGuard cited? (Yes/No + position), Snippet text
- Tools: Google Alerts for brand + "drainage"; Perplexity for testing

## Reports
- Weekly: GSC impressions/clicks, top queries, GBP views
- Monthly: Rank changes, organic traffic/leads %, AI citation rate, content performance
- Quarterly: Full audit vs plan KPIs (3-5x traffic, 50+ top keywords, 40%+ leads organic)

## Dashboard (Free)
Google Looker Studio:
- Connect GA4 + GSC
- Visuals: Organic sessions over time, top pages, keyword positions, lead sources

## Alerts & Tools
- GSC: Indexing drops, manual actions
- GA4: Traffic anomalies
- External: Uptime for site, citation alerts

Track against plan success metrics. Adjust content based on what gets clicks/citations.
